# docs/vault-export/

Notes written to be **copied into the Obsidian vault** (maghbu's brain, on the
founder's machine / USB drive) so the Claude agents that read the vault —
maghbu, maxxus — can orient without cloning this repo.

They live here too because the repo is the canonical, version-controlled copy.
The vault copy is a convenience mirror.

## Keeping them in sync

These files are **duplicated by hand** into the vault, so they can drift. Two
guards against that:

- Every note ends with a pointer stating that the repo wins if the two disagree,
  and names the file to check.
- Notes are written to be durable — they describe decisions, structure and
  constraints, not fast-moving values. Nothing here should need editing because
  a balance changed.

If you edit one of these, re-copy it into the vault. If you edit the vault copy,
port it back here.

## Obsidian notes

Files use YAML frontmatter and `[[wikilinks]]`. The wikilinks at the bottom of
each note point at vault pages that may not exist yet — Obsidian will show them
as unresolved until the corresponding notes are created. That's expected, not a
broken link to fix.
